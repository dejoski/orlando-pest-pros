# Osceola Pest Pros

Rank-and-rent pest control site for **Osceola & Orange Counties, FL**. Astro + Tailwind, deployed on Vercel.

## Pages

- Home + 6 service pages + 15 city pages + 90 city × service pages = **113 indexable pages**
- 404, thank-you, private analytics dashboard (`/dash-v9x4qm2k`, token-gated)

All content is data-driven (`src/data/*.json`) — no per-page files. Copy is generated; regenerate with
`python3 scripts/assemble.py` after updating the source JSON in `/tmp/copy/`.

## SEO

- Primary money keywords from `research/market-research.md` are baked into every city × service title/H1
  (`src/data/keywords.json`, generated by `scripts/assemble.py`).
- Sitemap priorities follow the research 10-page launch list.
- Schema: LocalBusiness (PestControlService, both counties in areaServed), Service, FAQPage, BreadcrumbList.
  Review schema uses **placeholder** reviews — replace with real ones before claiming them.

## Analytics

`public/track.js` → `POST /api/track` → Upstash KV. Dashboard at `/dash-v9x4qm2k?token=...`.
Set in Vercel: `KV_REST_API_URL`, `KV_REST_API_TOKEN`, `DASHBOARD_TOKEN`.
Fails open (204) when KV is absent; dashboard 404s without the token.

## Quote form

`POST /api/quote` validates server-side and redirects to `/thank-you/`.
Lead storage is currently a server log stub in `src/lib/leads.ts` — wire to KV/CRM before launch.

## Deploy

Push to `main` → Vercel auto-deploys. Set `SITE_URL` in `src/config.ts` to the final domain.
